# Excel 格式整理工具

一键清理脏数据、统一表格格式、格式互转，带图形界面，无需编程基础。

## 功能

### 一键清理
- 去除前后空格、删除空行/空列
- 删除重复行、清除特殊字符
- 支持保留中文/字母/数字模式

### 格式统一
- 统一字体（微软雅黑/宋体/黑体等）
- 统一对齐方式
- 列宽自适应
- 一键添加边框，表头加粗

### 格式转换
- Excel → CSV（支持utf-8/gbk编码）
- CSV → Excel

## 使用方法

### 直接运行（需Python环境）
```bash
pip install pandas openpyxl PySide6
python main.py
```

### 打包成EXE（无需Python环境）
双击 `build.bat`，完成打包后 `dist/Excel格式整理工具.exe` 可直接发给任何人使用。
